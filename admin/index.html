How to get an access token
  1. Sign in to GitHub with the shop's account and open New fine-grained token.
  2. Name it Crum admin and choose an expiry date.
  3. Under Repository access, choose Only select repositories and select crum and crum-orders.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Select Generate token, copy it and paste it above.

Keep the token private. Anyone who has it can change the website. If it is lost or shared, delete it on GitHub and create a new one.

Payment rule

Most customers in Pakistan prefer cash on delivery and are wary of paying an advance to a shop they do not know yet. Asking for an advance only on larger orders, after you accept them, keeps new customers comfortable while protecting you on Dawat orders.
